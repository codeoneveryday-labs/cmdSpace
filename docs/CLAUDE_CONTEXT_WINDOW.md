# Claude Code CLI: Context Window Monitoring, Token Extraction & Calculation Guide

> **Engineering Reference**: Technical specification and implementation guide for inspecting, extracting, and calculating real-time Context Window utilization in Anthropic Claude Code sessions.

---

## 1. Context Window Architecture in Claude Code

### 1.1. Core Invariants
Anthropic's **Claude Code** (`claude`) manages context dynamically using Claude 3.5 Sonnet, Claude 3.7 Sonnet, or Claude Opus models:

1. **Context Window Limit (`max_tokens`)**:
   - Claude 3.5 Sonnet & Claude 3.7 Sonnet: **200,000 tokens** standard capacity.
   - Claude Opus 4 / 4.5: **200,000 tokens** default, with optional 1,000,000 token extended tier.
2. **Anthropic Prompt Caching System**:
   - Claude Code heavily leverages Anthropic's server-side Prompt Caching (5-minute TTL, refreshed on read).
   - The token payload is reported under four distinct keys:
     - `input_tokens`: Uncached input tokens for the current turn.
     - `cache_read_input_tokens`: Tokens successfully retrieved from prompt cache.
     - `cache_creation_input_tokens`: New prompt tokens that were written to prompt cache for future turns.
     - `output_tokens`: Tokens generated by Claude in the response.
3. **Active Context Window**:
   - The effective context footprint occupying Claude's attention window for the turn is the sum of all input components:
     $$\text{Active Context Tokens} = \text{input\_tokens} + \text{cache\_read\_input\_tokens} + \text{cache\_creation\_input\_tokens}$$
4. **Auto-Compaction & Truncation**:
   - Claude Code issues `/compact` automatically when context approaches capacity (~85-90%), pruning tool call outputs, old file contents, and summarizing past dialogue into a single memory block.

## 2. Storage & Session Log Internals (`~/.claude/projects/`)

Claude Code maintains local session logs under the user's home directory.

### 2.1. File Location & Naming Convention
Logs are organized by workspace directory path:
```bash
~/.claude/projects/<escaped_workspace_path>/<session_id>.jsonl
```
*Where `<escaped_workspace_path>` replaces non-alphanumeric characters with hyphens `-` (e.g. `/Users/username/dev/my-app` becomes `-Users-username-dev-my-app`).*

### 2.2. JSONL Turn Structure
Each line in the session `.jsonl` file is an event or message turn. The assistant response event contains the `/message/usage` block:

```json
{
  "type": "assistant_response",
  "message": {
    "id": "msg_01AbcDef...",
    "model": "claude-3-5-sonnet-20241022",
    "role": "assistant",
    "usage": {
      "input_tokens": 1250,
      "output_tokens": 420,
      "cache_read_input_tokens": 45800,
      "cache_creation_input_tokens": 2400
    }
  }
}
```

---

## 3. Mathematical Formula for Context Window Percentage

$$\text{Active Context Tokens} = \text{input\_tokens} + \text{cache\_read\_input\_tokens} + \text{cache\_creation\_input\_tokens}$$

$$\% \text{ Context Window} = \left( \frac{\text{Active Context Tokens}}{200,000} \right) \times 100\%$$

*(If using an extended 1M context tier, replace 200,000 with 1,000,000).*

---

## 4. In-App Commands & Interactive Monitoring

Inside an active Claude Code interactive session:
- **`/cost`**: Displays token usage, prompt cache hit rate, and estimated dollar cost for the session.
- **`/context`**: Displays currently loaded files, memory files (`CLAUDE.md`), and token breakdown.
- **`/compact`**: Manually compresses conversation history to free context tokens.

## 5. Production Extraction Scripts

### 5.1. Standalone Python Script

```python
#!/usr/bin/env python3
import os
import glob
import json

def get_claude_context_status(cwd=None):
    if not cwd:
        cwd = os.getcwd()

    home = os.path.expanduser("~")
    # Escape cwd path according to Claude convention
    escaped_cwd = "".join(c if c.isalnum() else "-" for c in cwd)
    project_dir = os.path.join(home, ".claude", "projects", escaped_cwd)

    if not os.path.exists(project_dir):
        # Fallback: scan all project directories for newest session
        projects_root = os.path.join(home, ".claude", "projects")
        if not os.path.exists(projects_root):
            print("No Claude Code project directory found.")
            return
        candidates = glob.glob(os.path.join(projects_root, "*", "*.jsonl"))
    else:
        candidates = glob.glob(os.path.join(project_dir, "*.jsonl"))

    if not candidates:
        print("No Claude Code session logs found.")
        return

    # Find the newest session file by modification time
    newest_file = max(candidates, key=os.path.getmtime)

    # Read lines from newest file in reverse
    latest_usage = None
    model_name = "claude-3-5-sonnet"

    with open(newest_file, "r", encoding="utf-8") as f:
        lines = f.readlines()
        for line in reversed(lines):
            try:
                data = json.loads(line)
                msg = data.get("message", {})
                if "usage" in msg:
                    latest_usage = msg["usage"]
                    model_name = msg.get("model", model_name)
                    break
            except Exception:
                continue

    if not latest_usage:
        print("No usage event found in the current Claude session.")
        return

    inp = latest_usage.get("input_tokens", 0)
    cache_read = latest_usage.get("cache_read_input_tokens", 0)
    cache_create = latest_usage.get("cache_creation_input_tokens", 0)
    out = latest_usage.get("output_tokens", 0)

    active_tokens = inp + cache_read + cache_create
    max_context = 1000000 if "1m" in model_name else 200000
    percentage = (active_tokens / max_context) * 100

    print("========================================")
    print(f"Agent       : Claude Code CLI")
    print(f"Session Log : {os.path.basename(newest_file)}")
    print(f"Model       : {model_name}")
    print(f"Tokens Used : {active_tokens:,} / {max_context:,}")
    print(f"  - Input   : {inp:,}")
    print(f"  - Cache R : {cache_read:,}")
    print(f"  - Cache W : {cache_create:,}")
    print(f"  - Output  : {out:,}")
    print(f"👉 Context %: {percentage:.1f}%")
    print("========================================")

if __name__ == "__main__":
    get_claude_context_status()
```

### 5.2. Rust Native Integration (cmdSpace Bridge)

```rust
// Matches parser contract in cmdSpace `src-tauri/src/modules/agent_usage_parsers.rs`
const CLAUDE_CONTEXT_WINDOW: u64 = 200_000;

pub fn parse_claude_context(line: &str) -> Option<(u64, u8)> {
    let value: serde_json::Value = serde_json::from_str(line).ok()?;
    let usage = value.pointer("/message/usage")?;
    
    let input = usage.get("input_tokens").and_then(|v| v.as_u64()).unwrap_or(0);
    let cache_read = usage.get("cache_read_input_tokens").and_then(|v| v.as_u64()).unwrap_or(0);
    let cache_create = usage.get("cache_creation_input_tokens").and_then(|v| v.as_u64()).unwrap_or(0);

    let active_tokens = input + cache_read + cache_create;
    if active_tokens == 0 {
        return None;
    }

    let percentage = ((active_tokens * 100) / CLAUDE_CONTEXT_WINDOW) as u8;
    Some((active_tokens, percentage))
}
```
