# Overview

## Current Behavior

A forgotten remote password cannot be recovered from cmdSpace.

## Target Behavior

The Mac owner can confirm a reset in Settings, sign out every remote device,
and scan a fresh setup QR to create a replacement password.

## Affected Users

- The owner of the host Mac.

## Affected Product Docs

- `docs/product/remote-access.md`

## Non-Goals

- Remote or email-based password recovery.
